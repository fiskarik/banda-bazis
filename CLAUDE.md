# Банда «Базис» — кооперативные ограбления по математике

Браузерная кооп-игра, чтобы разбирать университетскую математику с друзьями (5+ человек одного курса).
Ноутбук — «большой экран» со сценой ограбления, у каждого игрока телефон — пульт своей части механизма.
Сейф открывается, только когда вместе получилось нужное преобразование. Охрана ходит обходом: кто крутит пульт, когда она смотрит, — шумит.
Дело №1 «Банк „Базис“» — линейная алгебра; дело №2 «Механическая усадьба» — теорема Шаля (тестовое).
Весь интерфейс и тексты — на русском.

## Как устроено
- Одна HTML-страница без внешних скриптов. Исходники в `src/`, `tools/build.py` склеивает их в одну страницу.
- Два способа связи; остальной код о них не знает (одинаковый интерфейс `presence` / `onPeers` / `onConnection`):
  1. **Локальная сеть (основной):** `dist/bazis_server.py` на ноутбуке (Python, только стандартная библиотека) отдаёт страницу
     и пересылает состояние по WebSocket. В странице это `LanRoom` из `src/net.js`; включается флажком `window.BAZIS_LAN`.
  2. **Артефакт в claude.ai:** комната Claude `window.claude.use("room")`, общее лобби, свои отличаются по коду комнаты.
- Синхронизация через presence: большой экран — источник правды, публикует состояние игры; телефоны публикуют значения
  пультов (`ctl`) и очередь нажатий (`acts`). Экран всё проверяет сам.
- Уровни генерируются детерминированно из (дело, код комнаты, раунд, номер этапа), поэтому экран и телефоны строят
  одинаковые уровни сами — по сети ходят только значения пультов.
- Подробно — протокол, поля presence, API уровня, фазы игры: `docs/ARCHITECTURE.md`.

## Файлы
| Путь | Что там |
|---|---|
| `src/core.js` | дела, уровни, допрос, генераторы, проверка значений пультов (`sanitizeRoleVal`). Работает и в Node |
| `src/widgets.js` | пульты телефона: выбор, шкала, точка, вектор, прямая, карточки, кнопки, радар сторожа |
| `src/render.js` | сцена большого экрана на canvas (своя отрисовка на каждый `kind` уровня), вспышки, баннеры |
| `src/music.js` | генеративная музыка на WebAudio: режимы `lobby/calm/play/check/siren/off`, звуки событий |
| `src/qr.js` | свой QR-кодировщик (байтовый режим, коррекция M) — QR-код входа в лобби |
| `src/net.js` | `LanRoom` (связь с сервером, переподключение) и `KeepAwake` (телефон не засыпает по http) |
| `src/app.js` | большой экран и телефон: фазы игры, охрана, тревога, экраны, связь |
| `src/page.html` | стили и места для скриптов (`/*@CORE@*/`, …) |
| `server/server_tpl.py` | сервер для локальной сети; страница встраивается при сборке вместо `__GAME_B64__` |
| `tools/build.py` | сборка → `build/index.html` (артефакт), `build/test.html`, `build/lan.html`, `dist/bazis_server.py` |
| `tests/` | проверки (ниже); `mockroom.js` — имитация комнаты Claude; `_common.py` — общие помощники |
| `docs/VOICE.md` | план озвучки заданий |

## Команды
На Windows Python может вызываться как `py` вместо `python`.
- Собрать после любой правки в `src/` или `server/`: `python tools/build.py`
- Запустить игру: `python dist/bazis_server.py` (сам откроет большой экран; телефоны входят по QR-коду из лобби)
- Быстрые проверки (~2 мин): `python tests/run_all.py --quick`
- Все проверки (~8 мин): `python tests/run_all.py`
- По отдельности: `node tests/test_core.js` (нужен Node.js), `python tests/test_server.py`, `python tests/e2e_lan_ui.py`,
  `python tests/e2e_lan.py [папка] [usadba,bazis]`, `python tests/e2e_guard.py`, `python tests/e2e_live.py`, `python tests/e2e_music.py`
- Для браузерных проверок один раз: `pip install playwright opencv-python-headless numpy` и `python -m playwright install chromium`
- Скриншоты проверок складываются в `shots/` — смотреть их глазами после правок интерфейса.

## Правила
- `build/` и `dist/` руками не править — только через `tools/build.py`.
- Страница самодостаточна: никаких внешних скриптов и библиотек. Шрифты Google — необязательные (в сети грузятся без ожидания).
- В JS-исходниках нельзя `</script` и невидимые символы (U+2028, U+00AD…) — сборка остановится.
- Сервер — только стандартная библиотека, Python 3.8+. Не ставить зависимостей для игры.
- Оба режима связи должны работать. Тронул связь или `app.js` — гоняй и тесты артефакта (`e2e_guard`, `e2e_live`),
  и тесты сети (`e2e_lan_ui`, `e2e_lan`).
- Presence: ключи только вида `[A-Za-z_][A-Za-z0-9_-]*` (комната Claude не пускает другие); presence большого экрана
  держать меньше 4 КБ (лимит комнаты Claude, `mockroom.js` его проверяет); id игроков начинаются с `p`.
- В генераторах уровней (`core.js`) — только `rng` из `makeRng`, никакого `Math.random`: иначе экран и телефоны разойдутся.
- Телефонам не доверяем: значения идут через `sanitizeRoleVal`, роли проверяются по раздаче (`asg`), нажатия — по номерам (`acts[].s`).
- Каждый уровень решается своим `solution()`, не решён в начале и раздаёт роли всем игрокам — это проверяет `tests/test_core.js`
  на 14 000 уровней. Новый уровень без зелёного `test_core.js` не готов.
- Тексты: по-русски, коротко, без канцелярита. Телефон обращается на «ты», большой экран — на «вы».
  Минус — `C.MINUS` (−), индексы — Unicode (A₁), формулы — HTML (`<sub>`, `.f`), не TeX.
- Большой экран — источник правды: любая новая механика считается на экране, телефоны только показывают и шлют нажатия.

## Как добавить уровень или дело
1. Генератор `lvXxx(rng)` в `src/core.js` возвращает объект уровня (поля — в `docs/ARCHITECTURE.md`), `null` — «перебросить кости».
2. Добавить его в `CASES.<дело>.levels` (+ комнату в `rooms`, тему в `topics`); для нового дела — запись в `CASES`, `CASE_IDS`,
   вопросы допроса `exam` и план здания `PLANS` в `src/app.js`.
3. Отрисовка сцены для нового `kind` — в `src/render.js`; новые виды пультов — в `src/widgets.js` (+ `sanitizeRoleVal`).
4. `python tools/build.py`, затем `node tests/test_core.js` и `python tests/run_all.py`.
