# Устройство игры

## Роли устройств
- **Большой экран** (ноутбук): держит всё состояние игры, считает шум, охрану, тревогу, цели уровня; рисует сцену; играет музыку.
- **Телефоны**: показывают свои пульты и шлют их значения и нажатия. Ничего не решают сами.

## Фазы
`lobby` → `intro` (сюжет и роли, ждём «Поехали») → `play` → `win` (2,6 с салюта) → `debrief` (конспект) →
следующий сейф (`intro`) … → `exam` (допрос на телефонах, у каждого свои числа) → `end` (итоги).
Режим «один экран» (`H.solo`): все пульты под сценой, без допроса.

## Механики большого экрана (`src/app.js`)
- Шум: каждое движение пульта +3,5, спадает на 14 в секунду.
- Охрана: `idle` → `warn` (6 с, слышны шаги, у сторожа на радаре отсчёт) → `check` (3,2 с, музыка стихает).
  Движение пульта во время проверки (первые 450 мс прощаются) — «поймали»: тревога +12%.
  Если на входе в проверку шум > 30 — тоже поймали.
- Ошибочное действие, подсказка (+8%), подсмотреть ответ (+25%, добыча 0), опоздание (+1% каждые 5 с после `par`).
- Тревога 100% — сирена 3,2 с, механизмы сбрасываются, тревога становится 55%.
- Цели с `latch` фиксируются, если продержались 0,6 с. Уровень пройден, когда все такие цели зафиксированы (или `evaluate` вернул `done`).
- Добыча за сейф (`C.levelLoot`): 100 − 12·поимки − 8·ошибки − 10·(подсказки + сирены) + до 20 за скорость, не меньше 20.
  Итог умножается на долю верных ответов на допросе.
- Игрок пропал больше чем на 6 с — его пульты передаются остальным (`H.vv++`). Вернулся — пульт получит со следующего сейфа.

## Связь: интерфейс комнаты
`app.js` работает с объектом комнаты, у которого:
- `presence(patch)` — слить `patch` в своё состояние (ключ со значением `null` удаляется), разослать другим;
- `onPeers(cb, onError)` → отписка; `cb({ peers })`, где `peers = [{ peer, isMe, sameTab, presence }]` (сам себя — `sameTab: true`);
- `onConnection(cb)` → отписка; `cb(true|false)`; `connected()`.

Реализации: комната Claude (`window.claude.use("room")`, артефакт), `LanRoom` (`src/net.js`, локальная сеть),
`tests/mockroom.js` (тесты, BroadcastChannel). Выбор — в `getRoomNs()` в начале `src/app.js`.

### Presence большого экрана (`hostPresence()`)
`app:"bazis"`, `host:true`, `code` (4 цифры), `rd` (раунд), `cs` (дело), `old` (со старым замком), `ph` (фаза), `lv` (номер этапа),
`nL` (игроков на уровне), `n`, `solo`, `seats` {pid → место}, `asg` {роль → место}, `cv` (значения пультов), `vv` (версия значений —
после сброса старые значения с телефонов не принимаются), `px` (открытая часть состояния уровня), `al` (тревога %), `nz` (шум %),
`gw` {id, ms} (охрана идёт), `gc` (id проверки, когда смотрит), `msg` {q, m, k} (последнее событие для тоста), `fin` {l, m} (итог).

### Presence телефона
`app:"bazis"`, `role:"phone"`, `code`, `pid` (`p` + 11 символов, живёт во вкладке — `sessionStorage`), `nick`,
`ctl` {vv, w: {роль → значение}}, `acts` [{s: номер, r: роль, t: тип, d: данные}] (последние 6 нажатий),
`ex` {cs, rd, i, s, n} (прогресс допроса).

## Сервер локальной сети (`server/server_tpl.py`)
- `GET /` — страница (gzip), `GET /info` — `{app, ver, port, id, ips}` (адреса ноутбука, лучший первым), `GET /ws` — WebSocket.
- Сообщения (JSON): от страницы `{t:"hi", cid, p}` (первым, с полным presence), `{t:"p", d}` (изменение), `{t:"hb"}`;
  от сервера `{t:"welcome", id, peers}`, `{t:"p", id, d}`, `{t:"bye", id}`, `{t:"hb"}` (каждые 4 с, страница отвечает сразу).
- Одна вкладка — один `cid`: при переподключении сервер выкидывает её старое соединение.
- Пределы: кадр 256 КБ, presence 64 КБ, 400 сообщений за 2 с, очередь на отправку 1 МБ (иначе устройство отключается),
  15 с тишины — отключение. WebSocket только со своей страницы (проверка Origin).
- Адреса: хот-спот Windows `192.168.137.1` первым, затем точки доступа телефонов, затем сеть с интернетом;
  виртуальные адаптеры (VirtualBox/эмуляторы, WSL, Hyper-V, VPN) — в конец. На Windows адреса берутся ещё и из `ipconfig`.
- Порт: 8000, если занят — 8080, 8001…; после открытия порта сервер проверяет, что на `localhost` отвечает именно он.
- Повторный запуск при работающем сервере просто открывает браузер.
- Страница переподключается сама (до 3 с между попытками), после сна телефона — сразу. Пока связи нет, `onPeers` отдаёт
  только себя, а `onConnection(false)` — телефон показывает «Нет связи с ноутбуком».

## Уровень (`src/core.js`)
Генератор `lvXxx(rng)` → объект (или `null`, тогда берётся следующее зерно):
- `kind` — тип сцены для `render.js`; `title`, `win` (фраза победы), `topic`, `par` (секунд на сейф);
- `story`, `goal`, `hint` — тексты (HTML-строки с Unicode-индексами); `theory` [{title, html}] — справка «Знатоку»;
- `roles(n)` → [{id, name, desc, w: [пульты], init, req?, seat?, dig?}] для n игроков; лишним — сторож (`look`) и знатоки (`know*`),
  см. `withExtras`. Виды пультов `w[].t`: `pick`, `dial`, `stepper`, `point`, `vec`, `line`, `compass`, `action`, `cards`, `key`, `radar`, `theory`;
- `initAux(n)` → внутреннее состояние уровня (обязательно `latched: {}`);
- `evaluate(V, aux)` → `{ goals: [{id, label, ok, latch?, hidden?, by?}], scene, done? }` — чистая функция от значений пультов;
- `act(aux, type, data, ctx)` → `{ noise?, alarm?, fx?, msg? }` — нажатия кнопок;
- `solution(aux)` → значения пультов, решающие уровень (подсмотреть ответ и тесты); `solve?(aux)`;
- `debrief(V, aux)` → HTML конспекта; необязательные `onChange`, `onLatch`, `expire`, `cardText`, `canon`, `nSteps` (доказательства).

Дело — запись в `CASES`: `levels`, `rooms`, `topics`, `exam` (генераторы вопросов допроса), `old` (повторение из другого дела).
Всё случайное — из `makeRng(строка)`: одинаковые входы дают одинаковые уровни на всех устройствах.

## Проверки (`tests/`)
- `test_core.js` — каждый уровень на тысячах зёрен: решается `solution()`, не решён в начале, роли розданы, тексты без `undefined`/`NaN`, HTML сбалансирован, допрос сходится.
- `test_server.py` — протокол сервера сырыми сокетами: обмен состоянием, куски сообщений, ping, выкидывание старого соединения, чужой Origin, большие кадры, медленный телефон, молчун.
- `e2e_lan_ui.py` — лобби в сети: QR читается, адреса переключаются, нет сети, падение сервера, ручной вход, неверный код.
- `e2e_lan.py` — оба дела через настоящий сервер: вход по QR, обрыв телефона, перезапуск сервера, перезагрузка телефона, допрос.
- `e2e_guard.py`, `e2e_live.py` — версия-артефакт с `mockroom.js`: охрана, сирена, подсказки, пауза, один экран, оба дела.
- `e2e_music.py` — громкость музыки по режимам.
