# Озвучка заданий — план

Цель: большой экран читает вслух то, что сейчас приходится читать с экрана, чтобы банда смотрела на сцену и на свои пульты.
Исследование вариантов голосов ещё не проводилось — пункты с пометкой **проверить** нужно подтвердить на ноутбуке и телефонах.

## Что озвучивать
| Когда | Что | Где в коде |
|---|---|---|
| Начало сейфа (`intro`) | место, название, сюжет, цель | `introHTML()`, `L.place`, `L.title`, `L.story`, `L.goal` |
| «Поехали» | короткое «Поехали!» | `go()` |
| Охрана идёт (`warn`) | «Охрана идёт» (без сторожа — вместо шагов; со сторожем — молчим, пусть кричит сторож) | `tickPlay()` |
| Охрана смотрит (`check`) | «Замрите!» | `tickPlay()` |
| Поймали / сирена | «Шум! Охрана услышала …» / «Сирена! Всё сначала» | `caught()`, `addAlarm()` |
| Цель зафиксирована | «Готово: …» (коротко, не чаще раза в пару секунд) | `tickPlay()` → `log("Готово…")` |
| Подсказка | текст подсказки (по кнопке) | `hostAct("hint")` |
| Сейф открыт | `L.win` | `win()` |
| Конспект | по кнопке «Прочитать конспект», не сам | `debriefHTML()` |
| Допрос | только «Допрос начался, отвечайте молча» — вопросы не читаем | `hostAct("next")` |

Телефоны по умолчанию молчат: все слушают большой экран. Личная озвучка роли в наушник — этап 3.

## Этап 1. Голос браузера на большом экране (без зависимостей)
1. Новый модуль `src/voice.js` (место `/*@VOICE@*/` в `src/page.html` перед `APP`, добавить в `PARTS` в `tools/build.py`):
   - `Voice.say(text, {prio, interrupt})` — очередь фраз с приоритетом: события (охрана, сирена) перебивают сюжет;
   - `Voice.stop()`, `Voice.setEnabled(bool)`, `Voice.setRate(x)`, `Voice.voices()`, `Voice.pick(name)`;
   - голос: `speechSynthesis.getVoices()`, русские (`lang` начинается с `ru`), предпочитать `localService` — работает без интернета;
     голоса приходят асинхронно — слушать `voiceschanged`; выбор помнить в `localStorage` (`bazis.voice`);
   - длинный текст резать на предложения (в Chrome длинные фразы бывает обрываются — **проверить**);
   - если русского голоса нет — кнопка голоса неактивна и подсказка «Установите русский голос в Windows».
2. Текст для речи отдельно от текста на экране. Функция `C.speakable(html)` в `src/core.js`:
   снять теги, заменить то, что голос читает плохо: «−» → «минус», «°» → « градусов» (с согласованием: 90 градусов, 1 градус…),
   индексы «A₁» → «A один», «A′» → «A штрих», «λ» → «лямбда», «φ» → «фи», «→» → «в», «·» → «на», дроби, векторы.
   При необходимости у уровня поле `say: { story, goal }` с готовым текстом для произнесения.
3. Музыка на время речи приглушается: `Music.duck(true/false)` в `src/music.js` — плавно опускать общую громкость (примерно до трети) и возвращать.
4. Интерфейс большого экрана: в шапке кнопка «Голос: вкл/выкл» рядом с «Музыка», на экране сейфа — «Повторить задание»,
   в лобби — выбор голоса и скорости (0,9–1,1). Настройки — в `localStorage`, как у музыки (`bazis.audio`).
5. Говорить только после жеста пользователя: первая фраза — после «Начать дело» / «Поехали» (браузеры блокируют звук без жеста).
6. Проверки (`tests/e2e_voice.py`): подменить `window.speechSynthesis` заглушкой, которая записывает фразы, и проверить:
   на интро прозвучали сюжет и цель; «Охрана идёт» и «Замрите» звучат в нужные моменты; выключенный голос молчит;
   музыка приглушается на время фразы и возвращается; `C.speakable` не оставляет в тексте «₁», «−», «°», тегов
   (это — в `tests/test_core.js` по всем уровням). Добавить проверку в `tests/run_all.py`.

**Проверить на ноутбуке:** какие русские голоса есть в Chrome / Edge / Яндекс Браузере (`speechSynthesis.getVoices()` в консоли);
есть ли русский голос без интернета (в Windows: Параметры → Время и язык → Речь / Язык → Русский → речь);
в Edge бывают более живые онлайн-голоса — с интернетом, возможно, лучше выбирать их.

## Этап 2. Качество: записанные заранее фразы (по желанию)
- Неизменные фразы (события, «Поехали», названия сейфов, сюжеты) озвучить заранее нейросетевым голосом
  (кандидаты — открытые TTS с русскими голосами, например Piper или Silero; **проверить** лицензии, качество, ударения).
- Файлы — в `server/voice/`, сервер отдаёт `GET /voice/<id>.ogg`; при сборке — список фраз и их id.
- `Voice.say` сначала ищет готовый файл, иначе говорит голосом браузера. Тексты с меняющимися числами — голосом браузера.
- Для артефакта в claude.ai файлов нет — там только голос браузера.

## Этап 3. Телефоны

- Сторожу — голосовое «Охрана через 3… 2… 1…» в наушник.
- **Проверить:** голоса на Android (Chrome) и iPhone (Safari) по http в локальной сети.
