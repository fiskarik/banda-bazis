# Банда «Базис»

Кооперативные ограбления по математике: ноутбук — большой экран со сценой, телефоны — пульты.
Сейф открывается, когда вместе получилось нужное движение или преобразование.

## Играть
1. Включите на ноутбуке мобильный хот-спот: «Параметры» → «Сеть и Интернет» → «Мобильный хот-спот» (до 8 устройств).
2. Запустите `dist/bazis_server.py` двойным щелчком или командой `py dist/bazis_server.py` — откроется большой экран.
   Окно сервера не закрывайте, пока играете.
3. Если Windows спросит про брандмауэр — отметьте и частные, и общественные сети.
4. Друзья подключаются к Wi‑Fi ноутбука, вы выбираете дело, они сканируют QR-код в лобби.

Телефон не открывает страницу: проверьте брандмауэр (в поиске «Пуск» — «Разрешение взаимодействия с приложением через
брандмауэр», у Python обе галочки), выключите на телефоне мобильный интернет и VPN. Хот-спот не включается без интернета —
раздайте Wi‑Fi с одного телефона и подключите к нему всех, включая ноутбук.

## Разрабатывать в Claude Code
- В приложении Claude: вкладка **Code** → окружение **Local** → **Open folder…** → эта папка.
- Или в терминале: перейти в эту папку и запустить `claude`.

Claude Code сам прочитает `CLAUDE.md` — там устройство проекта, команды и правила. План озвучки — в `docs/VOICE.md`.

Сборка: `python tools/build.py`. Проверки: `python tests/run_all.py --quick` (браузерным нужны
`pip install playwright opencv-python-headless numpy` и `python -m playwright install chromium`).
